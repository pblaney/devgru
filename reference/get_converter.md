# Convert using appropriate format-specific functions

Utilize the pre-built converters for various object formats. Available:

- dt –\> gr

- dt –\> gi

- gr –\> dt

- gi –\> bedpe

- gi –\> grl

## Usage

``` r
get_converter(input_obj, from_format, to_format)
```

## Arguments

- input_obj:

  Full path to file

- from_format:

  Character string of input object format "dt", "gr", "gi"

- to_format:

  Character string of input object format "dt", "gr", "gi", "grl"
