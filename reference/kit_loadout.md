# Build the devgru environment by installing/loading packages

Single command to install, if needed, and load all packages used in the
devgru kit.

## Usage

``` r
kit_loadout(update_kit = F)
```

## Arguments

- update_kit:

  Update all packages even if already installed, default: FALSE

## Examples

``` r
# Quick start devgru environment
# kit_loadout()

# Update the suite of packages used in the kit
# kit_loadout(update_kit = T)
```
