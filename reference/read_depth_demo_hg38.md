# dryclean-fragCounter read depth profile on hg38 as GenomicRanges

A slice of data from a `dryclean` adjusted `fragCounter` read depth
profile of a tumor sample. The demo contains slices from chr19 and
chr22.

## Format

`GRanges`

## Details

See `fragCounter` (https://github.com/mskilab-org/fragCounter) and
`dryclean` (https://github.com/mskilab-org/dryclean)
